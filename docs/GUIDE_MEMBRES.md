# Guide des membres du CER-PROMEDNAV

## Premier accès

1. Vous recevez un courriel d'invitation. Le lien vaut 72 heures et ne sert qu'une fois.
2. Choisissez votre mot de passe : au moins 12 caractères, avec une majuscule, une minuscule, un chiffre et un caractère spécial.
3. Installez une application d'authentification sur votre téléphone : FreeOTP, Aegis, Google Authenticator, Microsoft Authenticator, ou votre gestionnaire de mots de passe. Scannez le QR code, puis saisissez le code à 6 chiffres.
4. **Conservez les 10 codes de secours** hors du téléphone (papier, coffre). Chaque code ne sert qu'une fois.

## Connexion

Saisissez votre adresse et votre mot de passe, puis le code à 6 chiffres de l'application. Après 30 minutes d'inactivité, l'application vous déconnecte.

## Identifiants perdus

- **Mot de passe oublié** : « Identifiants perdus ? » → vous recevez un lien valable 30 minutes. Pour choisir le nouveau mot de passe, il faut aussi un code de l'application ou un code de secours.
- **Téléphone perdu** : connectez-vous avec un code de secours, puis « Mon compte » → « Changer de téléphone ».
- **Téléphone et codes de secours perdus** : contactez un administrateur. Il vérifie votre identité, puis réinitialise votre double authentification.

## Les dossiers

- La liste signale les dossiers nouveaux et les messages non lus.
- Les documents sont classés par pièce de l'annexe 3. Ils s'ouvrent dans l'application ; un bouton permet de les télécharger. Chaque consultation est inscrite au journal.
- **Commenter** (droit « lecture et écriture ») : rédigez votre analyse, en la rattachant si besoin à un document précis.
- **Répondre / compléter** : vous réagissez sous un commentaire existant.
- **Un commentaire publié est définitif.** Vous ne pouvez ni le modifier ni le supprimer. Pour corriger, publiez un complément.
- Vos commentaires portent votre nom et votre qualité, tels que l'administrateur les a enregistrés. Ils sont horodatés et signés.

## Conflit d'intérêts (art. 4.2)

Si vous êtes auteur, co-auteur ou investigateur du projet, si vous avez un lien hiérarchique direct avec le porteur ou un intérêt financier : cliquez sur **« Déclarer un conflit d'intérêts »**. Vous perdez alors l'accès au dossier et ne recevez plus ses notifications. La déclaration est définitive et visible des autres membres.

## Confidentialité (art. 5)

Les dossiers, les débats et les votes sont confidentiels. Ne transférez pas les documents hors de l'application. Les courriels de notification ne contiennent volontairement que la référence du dossier.

## Administrateurs

« Administration » permet de :

- créer un membre : nom complet (il signe les commentaires), qualité, adresse, droits ;
- modifier ses droits ;
- suspendre un membre : effet immédiat, ses sessions sont fermées ;
- renvoyer une invitation ;
- réinitialiser une double authentification ;
- consulter le journal et **vérifier l'intégrité** des commentaires et des documents.

Dans un dossier, « Administration du dossier » permet de changer le statut (recevable, en instruction, avis…), de basculer en procédure simplifiée et d'ajouter des documents (une nouvelle version n'efface jamais l'ancienne). « Saisir une demande reçue hors site » sert aux demandes arrivées par courrier.
